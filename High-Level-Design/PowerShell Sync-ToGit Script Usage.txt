The folder that actually writes to Git is "Git Wrestling Robe" while your local, protected-from-Git folder is "Wrestling Robe".
The following script pushes and commits all changes to Git from your Git Wrestling Robe folder that's local.  This was done to prevent Git from deleting, stashing, or otherwise tampering with files on your local drive.  The PowerShell script contained in this folder does the push and commit automatically for everything in the entire Wrestling Robe folder.  

PowerShell Sync Script Usage

# Basic usage (prompts for commit message)
.\Sync-ToGit.ps1

# With commit message
.\Sync-ToGit.ps1 -CommitMessage "Update ScholarSweep"

# Specify branch
.\Sync-ToGit.ps1 -Branch "Research-Corpus-Generation"
.\Sync-ToGit.ps1 -Branch "Document-Image-Analysis"
