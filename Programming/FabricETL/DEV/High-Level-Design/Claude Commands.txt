Custom Commands:
Bash(git:*) - pushes/merges/commits all changes across entire Git
/save - tells Claude to write a summary of what all we've done this session and are set to do next to file "CLAUDE.MD"

Frequently-used:
claude --dangerously-skip-permissions
get rid of "proceed?" prompts in CLI

CLI Flags (when starting Claude):
Flag	Description
claude	Start interactive session
claude "prompt"	Start with initial prompt
claude -p "prompt"	Print response, no interactive mode
claude -c	Continue last conversation
claude -r "session-id"	Resume specific session
claude --model <model>	Specify model (opus, sonnet, haiku)
claude --dangerously-skip-permissions	Skip all permission prompts
claude --max-turns <n>	Limit agentic turns
claude --output-format <format>	Set output (text, json, stream-json)
claude --allowed-tools "Tool1,Tool2"	Pre-approve specific tools
claude --disallowed-tools "Bash(rm*)"	Block specific operations
claude --verbose	Enable detailed logging
claude --version	Check version
claude update	Update Claude Code
claude doctor	Diagnose issues
claude config	Configuration wizard
claude mcp	MCP server management
